# Fictional learning journey: review record

This source adds an optional public `#sample-week` journey using the existing Repformed identity. It is not weekly-learning activation, a fulfilled package week, trusted grading, coaching approval or a native app release. Public enrollment stays closed. Homepage design, package benefits, interest collection and consent remain unchanged.

## What the sample does

- A short draft IQ lesson and an original field diagram, explicitly pending review. Marketing stock footage is not reused as instructional video.
- Two browser-scored sample questions. Required answers, single submission, retry history, navigation and reset/cancel behavior are observable. No private quiz keys, accounts, backend grade writes or emails are involved. This public illustration's answers are intentionally public; production quizzes still need their separate protected server-scoring acceptance.
- A practice-format view showing the necessary instruction, prescription, cue and safety fields, with an explicit missing-reviewed-media state. No drill is assigned or marked performed.
- Progress separates marked-read text, sample recall score, viewed format and actual coaching assessment. Feedback is described as a format, never fabricated as a delivered coach review.
- All sample state is memory-only, clears on reload or leaving/re-entering the route, and cannot create an athlete/customer record. App-mode/native entry redirects to the existing authenticated app surface. Existing fictional family-practice deep links remain functional.

## Asset evidence and remaining content gate

`public/media/credits.txt` identifies the repository's existing video as marketing atmosphere, not coaching lessons. The ordinary anonymous catalog check on 2026-10-29 returned HTTP 401. No alternate credential was used; the private catalog was not inspected. This does **not** establish that private approved assets do not exist.

An actual representative product demonstration still needs owner-supplied, licensed, qualified-reviewed IQ and drill media, plus review of the draft lesson text. This preview does not close that content gate or demonstrate production Sunday release/Friday reminder behavior.

## Acceptance and release boundaries

Check complete/partial quiz answers, repeated submit, retry history, state retained between steps, cancel/confirm reset, reload, browser Back, keyboard focus, 320/390/1440 px, sampled accessibility and no backend writes. Run the exact final source's normal lint/types/unit/build/browser/app/offline checks before release. Record isolated preview URL/source separately from production. Never promote a disabled-backend preview artifact to production.

No new database migration, permission, service, credential, scheduler, private media, paid enrollment or notification integration is part of this change. PR21 server roster paging and PR13 weekly learning remain independent and gated.
