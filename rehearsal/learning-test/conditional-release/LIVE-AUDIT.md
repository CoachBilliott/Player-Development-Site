## Execution discipline and severity

- Run only against the explicitly recorded environment/source. A disabled feature, missing endpoint or empty dataset is **not** a passing isolation test.401/403 must be a genuine application/provider permission denial, not a network challenge.200 empty is a valid row-denial result only with a known own positive control/nonempty controlled counterpart. Never count a local mocked grade/order as live server behavior.
- Inspect public/own-context links, UI empty/loading/error states, keyboard/focus,320/375/390px wrapping, auth restore/back/cancel, package availability and contact/social links. Reuse the prior approved interest canary receipt; do not submit another request, recovery email or notification while the owner sleeps.
- Negative **write** tests, assignment changes, expiry/revocation, role changes, quiz attempts/grades and uploads require the approved controlled fixture scope. Do not fire a forbidden role-grant/delete request against real accounts merely to see whether the server accepts it. Read-only copied-route/API checks are safe, but they do not fully verify mutation protections.
- For private media, use approved known controlled paths; do not enumerate or guess child files. Verify authenticated own access and cross-scope denial. Existing signed URLs can remain valid until expiry; do not claim immediate revocation. Never publish the URLs.
- Critical: unauthorized private data/media/answer-key access or role/household takeover. Stop that path, retain minimal redacted evidence and notify the parent promptly; no broad exploitation/dumps. High: wrong-athlete delivery/grade mutation, destructive replacement, lost submission or broken authentication. Medium: materially confusing/unusable navigation or inaccurate service status. Release blockers/untested gates are categorized separately from proven runtime vulnerabilities.
- A finding needs actual reproduction/environment and a fix+regression receipt. Do not weaken an authorization check to turn a failing audit green. Do not declare all roles passed until every planned actor/case is actually covered or an explicit limitation is accepted.
