PLAYER DEVELOPMENT — PARTNER WALKTHROUGH

Guide baseline: private pilot build 10, October 2026.

guide.json is the shared content source for partner-guide.html and
partner-guide.pdf. Run python3 scripts/build-partner-guide.py with ReportLab
and the system DejaVu Sans fonts installed to regenerate both. Set
PD_GUIDE_FONT_DIR to override /usr/share/fonts/truetype/dejavu. Embedded
PDF font licensing is provided in font-license.txt. CSS and share.js provide responsive layout and
optional link copying; all guide instructions remain readable without JavaScript.

Images are original product screenshots captured in Chromium against the actual
website, with the repository's intercepted fictional backend fixture. The public
homepage uses the project's existing licensed media (see ../media/credits.txt).
Private workspace captures contain fictional accounts, text attachments and
participation only. They are browser previews of the shared app UI, not native
Photos/camera screenshots, real player records or coaching demonstrations.
No actual customer data, accounts, assignments, uploads or messages were changed
to make the screenshots. Source capture procedure is described in
PARTNER-GUIDE.md at the repository root.
